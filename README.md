# Code.House

Static website for the domain **code.house** — free developer guides, browser-based tools, a learning roadmap, a curated video index, and enquiry routes for projects, sponsorship, advertising, partnership and the domain itself.

No build step, no framework, no dependencies. Plain HTML, one stylesheet, two scripts.

## Live

Intended home: `https://code.house` (a `CNAME` file in this repo sets the custom domain).

**To publish:** Settings → Pages → Source: *Deploy from a branch* → branch `main`, folder `/ (root)` → Save.

## Advertising

The Google AdSense tag (`ca-pub-6620975821265271`) is in the `<head>` of every page, together with `ads.txt` and the `google-adsense-account` meta tag.

Reserved ad containers are placed in the content of every substantial page. Each one is **hidden** until a real slot id is supplied, so the site never shows an empty ad box before approval:

```html
<ins class="adsbygoogle" data-ad-client="ca-pub-6620975821265271"
     data-ad-slot="REPLACE_WITH_SLOT_ID" data-ad-format="auto"
     data-full-width-responsive="true"></ins>
```

After AdSense approval, create display units in the dashboard and replace `REPLACE_WITH_SLOT_ID` with each unit's id. The containers then reveal themselves automatically (see `fillSlots` in `assets/js/site.js`). Auto ads can be switched on in the dashboard instead, with no code change.

A cookie notice offers *Accept all* or *Essential only*; choosing the latter stores a preference that sets `requestNonPersonalizedAds` before the tag loads. For EEA, UK and Swiss traffic, enable Google's certified CMP in the AdSense dashboard as well.

## Contact routing

Every page carries a top bar linking to the partnership contact page, and all enquiry forms build a `mailto:` message in the browser. Both destinations are decoded at runtime in `assets/js/site.js` rather than written into the markup, so no address appears in the page source.

## Rebuilding

The site is generated by a small Python script (kept outside this repo):

```
python3 build.py     # writes dist/
python3 qa.py        # link, metadata, thin-content and leaked-string checks
```
