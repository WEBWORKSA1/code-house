Why browser-based tools

Most online formatters and converters send your input to a server to do the work. For a configuration file, an API response or a token, that means pasting potentially sensitive data into someone else's logs. Every tool on this page is written in plain JavaScript and performs its work locally, so the data never leaves the tab.

They are also deliberately small. There is no account, no paywall after three uses and no upload step. Open the page, paste, read the answer.
